# Image Gallery

This is an image gallery I built with HTML, CSS and JavaScript. I wanted it to do more than just show pictures, so I added controls for viewing and moving between them.

## Features

- View pictures in the gallery
- Switch between dark and light themes
- Open and close the side menu
- Start a slideshow and move through the pictures
- Navigate between pictures using the gallery controls
- Filter pictures using the filter control
- Responsive styling for different screen sizes

## Built With

- HTML
- CSS
- JavaScript

## How to Run It

1. Clone or download this repository.
2. Keep the HTML, CSS, JavaScript and image files in the folders expected by the project.
3. Open the main HTML file in your browser.

If the project uses local image paths, make sure the image files are included when you upload the project to GitHub.

## What I Practised

This project helped me practise working with the DOM, event listeners, arrays, functions, CSS transitions and changing page content with JavaScript. I also worked on connecting the menu, theme switch, image filter and slideshow controls.

## Notes

The gallery depends on the image files included with the project. If an image does not appear after deployment, check that its file path and filename match the actual file, including letter case.
