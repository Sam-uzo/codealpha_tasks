# Calculator

I built this calculator with HTML, CSS and JavaScript as part of my frontend development practice.

It handles the basic arithmetic operations and has a few extra features that make it easier to use.

## Features

- Addition, subtraction, multiplication and division
- Live result preview while entering a calculation
- Clear the display or delete the last character
- Keyboard support for entering numbers and performing calculations
- Percentage conversion
- Dark and light themes, with the selected theme saved in the browser
- Previous results displayed in a dropdown
- Error messages for invalid calculations, including division by zero
- Responsive layout for smaller screens

## Built With

- HTML
- CSS
- JavaScript

## How to Run It

1. Clone or download this repository.
2. Keep `index.html`, `style.css` and `script.js` in the same folder.
3. Open `index.html` in your browser.

No additional packages are required.

## Keyboard Controls

| Key | Action |
| --- | --- |
| `0–9` | Enter a number |
| `+`, `-`, `*`, `/` | Enter an operator |
| `.` | Enter a decimal point |
| `Enter` | Calculate the result |
| `Backspace` or `Delete` | Delete the last character |
| `Escape` | Clear the display |
| `%` | Convert the displayed number to a percentage |

## What I Practised

Working on this project gave me practice with DOM selection, event listeners, functions, input validation, CSS styling and updating the page with JavaScript. I also worked on making the calculator respond to both button clicks and keyboard input.

## Notes

The calculator handles basic arithmetic expressions. It does not currently support brackets, powers or square roots.
